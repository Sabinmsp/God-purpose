# Tiny Town

Kenney's Tiny Town, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The 16px tile atlas comes from [Kenney](https://kenney.nl/assets/tiny-town) via the
[openClawWorld copy](https://github.com/Two-Weeks-Team/openClawWorld/blob/main/packages/client/public/assets/kenney/tiles/tinytown_tilemap.png).
Four Wins assembles its own buildings and paths from individual tiles and adjusts their colors.
